# Third-party notices

## macOS app

The macOS app has **no third-party code dependencies**. It is written in Swift against Apple's system
frameworks only (AppKit, SwiftUI, ScreenCaptureKit, Core Image, Core Graphics, ImageIO, Carbon
HIToolbox, ServiceManagement), which ship with macOS and are not redistributed.

Assets used at runtime but **not included** in this repository or the built app:

| What | Where it comes from | Terms |
|---|---|---|
| SF Symbols (toolbar and menu icons) | Loaded by name from macOS at runtime | Apple's SF Symbols licence: may be used in apps that run on Apple platforms, not modified into other glyphs |
| SF Pro (interface text) | The macOS system font | Part of macOS |

The app icon is generated by `scripts/make-icon.swift` and the capture sound (`assets/sounds/capture.wav`)
by `scripts/sounds.mjs`. Both scripts are part of this repository and covered by its MIT licence.

## Windows app

The Windows app in `windows/` is built on open-source packages that are compiled into it. Their licences
travel with the packages (`windows/node_modules`, `cargo` registry):

| Package | Use | Licence |
|---|---|---|
| [Tauri](https://tauri.app) 2 and its plugins (autostart, dialog, single-instance) | App shell, windows, tray | MIT or Apache-2.0 |
| [windows](https://github.com/microsoft/windows-rs) | Win32 APIs | MIT or Apache-2.0 |
| [image](https://github.com/image-rs/image), notify, trash, arboard, serde, chrono, log, parking_lot, crc32fast, sha1_smol | Image files, folder watching, Recycle Bin, clipboard, settings | MIT and/or Apache-2.0 |
| [Svelte](https://svelte.dev) 5 | Interface | MIT |
| [Lucide](https://lucide.dev) (`@lucide/svelte`) | Icons | ISC |

Segoe UI, the interface font, is part of Windows and is not redistributed.
